## Quartz 文档排序机制（调研+修复）

### 问题
ItalianRead 列表页 `racconti/` 下的故事看似"随机乱序"——01 Novellino 出现在末尾、修复轮文件插入其他位置。

### 排查链
1. **PageList.tsx** 默认排序 `byDateAndAlphabeticalFolderFirst`：文件夹优先 → 双方有日期则按 modified 倒序 → 无日期则标题字母序
2. **explorer 侧边栏**：localeCompare(numeric: true)，文件名编号起作用；这层始终是 01→N 正序
3. **created-modified-date 插件**：只读 frontmatter `created/modified/published`，**不读 `date:`**——之前以为改了 date 影响排序是错觉
4. ItalianRead 故事的 `date:` 字段是批量生成时刻（5分钟递增），与文件名编号无关

### 修复方案（用户审批）
**每文件夹一个统一 modified = 该目录精读启动日**，触发稳定排序 → 输入序 = 文件名序 = 01→N 正序。
